# Сведения о Git
## Основные команды
_Все начинаются с git._
- `init`
- `clone {ссылка на репозиторий}`
- `push`
- `push -u origin main`
- `commit -m {комментарий}`
- `status`
- `add .|--all|{имя файла}`
- `remote -v`
- `remote add origin {ссылка на репозиторий}`

## Зачем нужен?
`Git` позволяет управлять проектами, работая с ними коллективно и отслеживая изменения. Вещь невероятно полезная, а научиться ей пользоваться можно всего за вечер. Ну что за чудо!
